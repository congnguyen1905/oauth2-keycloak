Admin Area

Chào admin! Bạn có quyền ROLE_ADMIN.

✅ Quyền truy cập xác nhận Bạn đã được Keycloak cấp quyền ROLE_ADMIN. Endpoint /api/admin/stats của Resource Server cũng sẽ cho phép bạn.
🔑 Cách gọi Admin API Lấy access token từ Dashboard, sau đó gọi: GET /api/admin/stats với header Authorization: Bearer <token>
